# ORYQEN V7 — Living Guardian

This is a genuine React Three Fiber 3D robot, not an animated PNG.

## Improvements over Claude source
- Sculpted three-dimensional cheek armour, recessed navy inlays and emissive channels
- Articulated chin guard and glowing mandibular trim
- Side temple blades for a more sophisticated helmet silhouette
- Replaced the protruding antenna with a low-profile neural receiver
- Preserved head gaze tracking, 360-degree orbit, responsive framing, idle animation and adaptive DPR
- WebGL failure continues to show an explicitly labelled static fallback

## Run
`npm install` then `npm run dev`. Test in normal Chrome.

## Limitations
This is a detailed procedural humanoid robot, not the photorealistic sculpted character in the reference. Achieving that quality requires a professionally modeled/textured GLB or custom Blender work. Browser GPU behavior still needs validation on the target laptop.
